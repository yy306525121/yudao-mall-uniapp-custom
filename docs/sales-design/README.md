# 新时代商城全站样式重构

依据《新时代销售平台移动端设计规范》V2.0（2025.10.17）新版样式。750px 画板的设计尺寸使用 rpx 表达。

## 实现范围

- 全部 58 个已注册路由：原有核心购物页面，以及本次新增覆盖的 43 个页面，包括营销商品、活动、分销、钱包、充值、评价、售后、物流、客服、设置、错误页和自定义装修页。
- 页面主题由 `sheep/hooks/useSalesDesign.js` 中的全站路由列表启用；布局向子组件提供相同主题，页面声明的插槽组件使用所属页面路由兜底。缓存页面不会随其他页面切换而换色。
- `sheep/scss/_sales-design.scss` 提供按钮与卡片的复用样式；`s-layout` 提供颜色变量。主题优先于用户存储的旧主色和深色设置，未注册路径不自动启用。
- 装修仅生成展示副本，不修改模板存储：保留内容、模块顺序、跳转、字段显示开关、商品布局模式和媒体地址。图片组件保留图片；容器背景、颜色、字体、间距及圆角按规范统一。广告弹层及悬浮入口不新增卡片占位。
- 核心四个底部入口复用现有图标字体，统一蓝色选中态；其他后台配置的入口继续使用原图标。
- 未修改后端接口、请求参数、响应结构、业务流程和数据库；微信公众号登录回调页面保持原逻辑。

## 当前环境限制

- 本机未发现微信开发者工具；以上截图来自 H5 浏览器，不能替代小程序真机、安全区和键盘交互验收。
- 当前未登录，没有可用测试账号，因此未验证登录后购物车增减、提交订单、地址保存、订单不同状态与真实支付；没有提交交易或发送短信。
- 部分后台配置的运营图 `file.sheepjs.com` 报证书错误，部分商品图片地址返回 404。截图如实保留缺图，没有替换真实资源。
- 首页现有优惠券组件把接口返回的 `null` 直接赋给列表，读取 `.length` 时发生异常。该组件未修改；它限制了首页完整内容验收，需接口返回有效列表或另行处理空值。
- 普通详情页的当前接口返回过“系统异常”提示；页面展示和规格弹窗可检查，不能据此认定购物流程已端到端通过。

## 本次全站检查补充

- 微信小程序使用 HBuilderX 配套编译器发布编译通过，未修改依赖清单；保留原有 img 选择器和三项鸿蒙平台判断提示。
- 43 个新增覆盖页面的业务脚本与原代码逐一核对，保持一致。修改集中于模板的展示属性、样式及主题适配；不改变请求、提交、消息或支付处理。
- 在 H5 实际打开优惠券、秒杀、钱包、充值、分销中心、售后列表、评价列表、签到、客服、设置和网络错误页，390px 下均未发现文档横向溢出。
- 充值（含登录协议弹窗）、秒杀、客服在 320px / 430px 下检查，文档无横向溢出；秒杀时间项保持原有横向滚动。
- 商品标题进行了临时超长文本布局压力检查：多行省略生效，文档无横向溢出；检查后恢复真实文本，截图保留真实数据。
- 修正了充值卡片的固定宽度、登录协议的过大内边距和关闭图标位置，避免小屏裁切；分销中心改用普通导航，修正浅底白字。
- 当前未登录导致受保护接口返回 401，部分原有页面会输出未捕获异常。钱包、分销和售后只验证页面框架、登录弹窗及空状态，不能视为登录后完整业务验收。
- 当前签到数据返回“活动还未开始”，优惠券与评价列表为空；客服无真实会话数据。多状态记录、消息气泡、上传结果、键盘真机交互及真实交易仍待测试账号与数据。
